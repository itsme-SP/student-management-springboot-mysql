# Student Management System

A backend-based Student Management System developed using **Spring Boot**, **Spring Security**, **JWT Authentication**, **Hibernate/JPA**, and **MySQL**. The application provides secure REST APIs for managing student records with role-based authentication and CRUD operations.

## 🚀 Features

* Secure user authentication and authorization using **Spring Security** and **JWT**.
* Role-based access control for Admin and Student users.
* Complete CRUD operations for managing student records.
* RESTful APIs integrated with **MySQL** using **Spring Data JPA/Hibernate**.
* Input validation, exception handling, and layered architecture (Controller, Service, Repository).

## 🛠️ Tech Stack

## ⚙️ Getting Started

1. Clone the repository.
2. Configure your MySQL database in `application.properties`.
3. Build the project using Maven.
4. Run the Spring Boot application.
5. Access the REST APIs using Postman or any API client.
